HexNote

A free, open-source alternative to Confluence

What is HexNote?

HexNote is a free desktop wiki that stores your documents as markdown files on your own Google Drive. You own your data forever. No subscriptions, no vendor lock-in, no surprise deletions.

If Atlassian can delete your entire workspace for not logging in within a certain amount of time, you don't own your data. HexNote fixes that.

Pages live in a tree of folders. The status line says whether teammates can see your latest text.

Features

  • Rich text editor — headings, bold, italic, code blocks, tables, task lists, images
  • Google Drive storage — your docs are .md files on YOUR Drive
  • Publish/Draft workflow — edit on your PC, publish when ready; HexNote warns you before overwriting a teammate's newer version
  • Workspace sharing — share a Drive folder; teammates' published pages arrive automatically
  • Image support — paste or drag images, stored on Drive
  • Version history — every publish creates a Drive revision you can restore
  • Full-text search — instant search across all your pages
  • Dark mode — because of course
  • Offline capable — local cache works without internet

Getting started

HexNote connects to Google Drive through a Google Cloud project that you own, so no one else (including the HexNote authors) ever handles your sign-in. Setting that up is a one-time job of about 10 to 15 minutes. It is free.

  1. Create Google Cloud credentials. In Google Cloud Console: create a project, enable the Google Drive API, create an OAuth client ID of type Desktop app, and download its JSON file. The step-by-step guide walks through every screen.
  2. Set the consent screen to In production. While it says Testing, Google signs you out every 7 days.
  3. Open HexNote and paste the JSON. The first screen asks for it and shows the same guide.
  4. Sign in with Google in the browser window that opens.
  5. Choose or create a Drive folder for your workspace, or join a folder someone shared with you.

Working with a team? The person who created the Cloud project can share the same credentials file with teammates (add them as test users if the project is still in Testing).

How it works

  • Everything you write is saved on your PC first. The status line says Saved on this PC · not published.
  • Publish puts the page on Google Drive as a .md file (images go in an assets folder, linked with relative paths so the files work in any markdown viewer).
  • Teammates' HexNote refreshes from Drive every couple of minutes and whenever the window comes back to the front.
  • Every publish is a Drive revision you can preview and restore.
